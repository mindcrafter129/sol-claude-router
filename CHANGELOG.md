## [1.0.0] - 2026-08-15

### Added

- First stable npm release.
- Publish-ready npm package metadata and installation documentation.
- Contribution and security policies.

## [0.1.0] - 2026-08-15

### Added

- Official Codex CLI browser OAuth login, logout, status, refresh, and dedicated credential storage.
- Anthropic-compatible loopback Messages API for Claude Code.
- GPT-5.6 Sol, Terra, and Luna model selection.
- Reasoning effort selection from low through ultracode-compatible xhigh workflows.
- Streaming text, tool calls, tool results, reasoning, usage, errors, and cancellation translation.
- Process-scoped Claude Code launcher that leaves normal `claude` authentication unchanged.
- Protocol, tool, streaming, error, and cancellation tests.
